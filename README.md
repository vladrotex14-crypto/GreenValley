# Легенды Зелёной Долины — Android

Это ранний игровой прототип на русском языке, упакованный в Android WebView.

## Сборка APK без компьютера через GitHub Actions

1. Распакуйте ZIP-архив на телефоне.
2. Создайте пустой репозиторий GitHub с веткой `main`.
3. Загрузите **содержимое** папки проекта в корень репозитория, сохранив структуру, включая скрытую папку `.github/workflows`.
4. Откройте вкладку **Actions** → **Build Android APK** → **Run workflow**.
5. Дождитесь зелёной галочки, откройте запуск и скачайте артефакт **GreenValley-Android-APK**.
6. Распакуйте полученный ZIP и установите `app-debug.apk`.

Важно: GitHub не распаковывает ZIP, если просто загрузить его как один файл в репозиторий. Нужно загрузить именно распакованные файлы с папками. Сборка требует доступа к GitHub Actions и сети.
