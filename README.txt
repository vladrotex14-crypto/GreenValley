Легенды Зелёной Долины — Android проект (прототип)

1. Откройте папку GreenValleyAndroid в Android Studio.
2. Дождитесь Gradle Sync (потребуется Android SDK и интернет для зависимостей).
3. Выберите Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Это оболочка WebView вокруг текущей HTML-игры, работает офлайн после установки.
APK не включён: в среде создания проекта нет Android SDK и доступа к репозиториям сборки.
